# Do And Don't

Use this file to keep the output tactful and human.

## Do

- write like a real person who understands context and relationships
- reduce psychological burden on the recipient
- preserve the user's real objective
- make requests clear enough to act on
- soften edges without erasing accountability
- prefer concrete wording over decorative wording

## Don't

- sound like a generated template
- stack politeness phrases to create fake warmth
- use vague empathy with no substance
- turn every message into a mini speech
- make assertive content so soft that the point disappears
- sound like a customer service macro unless the user explicitly wants that tone

## Common AI-Smelling Patterns

Watch for these patterns and rewrite them:

- repetitive gratitude such as multiple "感谢/辛苦/理解"
- excessive transition words that make the message feel engineered
- over-rounded wording that avoids saying the real ask
- emotionally polished lines that no one would actually send in chat

## Low-Burden Communication Signals

These qualities usually help:

- short opening
- clear purpose
- reasonable ask
- space for the recipient
- calm close

## Pressure Signals To Reduce

Reduce these unless the user explicitly wants a stronger tone:

- implied blame
- deadline pressure without context
- repeated follow-up phrasing
- moral pressure such as "麻烦尽快" without need
- over-detailed self-justification
